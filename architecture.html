🎨 Component Legend

📹 Input Layer
Camera feed and training dataset
⚙️ Processing Layer
Face detection and recognition logic
🤖 Model Layer
Trained ML models and mappings
💾 Data Layer
Database and configuration files
🖥️ Interface Layer
User interfaces and APIs
🔧 Utility Layer
Helper functions and services

🔄 Data Flow Overview

  1. Training Phase: Dataset images → Face detection → LBPH training → Model generation
  2. Recognition Phase: Live camera → Face detection → Face matching → Attendance marking
  3. Management Phase: Admin interface → Database queries → Data visualization/export
